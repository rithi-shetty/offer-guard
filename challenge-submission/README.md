# Original challenge submission

What was submitted to the **Razorpay AI PM Build Challenge, Track 2: Recover and Grow with AI**. Offer Guard reached the semi-finals. These files are kept unchanged so the starting point stays visible.

| File | What it is |
|---|---|
| [Product_Note.pdf](Product_Note.pdf) | Two-page product note: problem, evidence, decisions, metric, next steps |
| [Pitch_Deck.pptx](Pitch_Deck.pptx) | 10-slide deck with speaker notes |
| [Demo_Video.mp4](Demo_Video.mp4) | 90-second walkthrough of the prototype |
| [AI_Build_Log.md](AI_Build_Log.md) | How AI tools were used, and the AI outputs that were rejected |
| [prototype-v1.html](prototype-v1.html) | The single-file prototype. Its estimates were simulated, not produced by a model |

The portfolio version (v2) in the rest of this repository keeps v1's product design and replaces the simulated estimates with a trained uplift model, a simulator, experiments and tests. [`tools/build_dashboard.py`](../tools/build_dashboard.py) shows every change made to the v1 page.
